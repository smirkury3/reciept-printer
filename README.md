Can be used for ESC/POS printers from linux
I am not planning to make versions for other operating systems
syntax is: Usage: ./print 'text' (formatting)
	(formatting) Use this to change the formatting, you can do this in command-line arguments 	2, 3, 4 and 5
-g) makes text larger
-s) makes text smaller
-r) aligns text to right
-l) aligns text to left
-b) makes text bold
-u) single underlines text
-U) double underlines text

port is defaulted to USB0, if your port is different, you can change the top line
